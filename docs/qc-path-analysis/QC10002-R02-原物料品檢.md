## 二、第一層：路徑 → QC 標籤映射

### 2.1 觸發條件（FOLDER_QC_MAP）

```javascript
const FOLDER_QC_MAP = {
  '半成品品檢表': 'QC10006-R02',
  '原物料品檢': 'QC10002-R02',
  '進料檢驗': 'QC10002-R02',
  // ... 其他映射（出貨檢驗、裝配巡檢、零組件入庫、完成品品檢、QIP/射出/押出檢驗）
};
```

**匹配規則**（`detectQCFromFolder` 內依序執行）：
1. 資料夾名含 `QC\d{5}-R\d{2}` 表單編碼（如 `QC10002-R02`）→ 直接回傳該編碼
2. 否則依 `FOLDER_QC_MAP` 關鍵字比對：資料夾名含「原物料品檢」或「進料檢驗」→ QC10002-R02（完整鍵列表見原始碼）

**實現函數**：[`detectQCFromFolder()`](../../src/utils/browserETL.js#L97-L105)

```javascript
export function detectQCFromFolder(dirname) {
  const m = dirname.match(/QC\d{5}-R\d{2}/i);
  if (m) return m[0].toUpperCase();
  const keys = Object.keys(FOLDER_QC_MAP);
  for (let i = 0; i < keys.length; i++) {
    if (dirname.indexOf(keys[i]) >= 0) return FOLDER_QC_MAP[keys[i]];
  }
  return null;
}
```

### 3.2 映射邏輯

```javascript
export function getRawSubCategory(qc, relPath, fileName) {
  if (qc === 'QC10002-R02') {
    const parts = relPath.split('/');
    const p0 = parts[0].replace(/[-_]20\d{2}$/, '').replace(/\s+/g, '');
    
    if (p0 === '原料') return '原料';
    
    if (p0.includes('物料')) {
      if (parts.length > 1) {
        let sub = parts[1].replace(/[-_]20\d{2}$/, '').trim();
        // Ensure standard prefix
        if (!sub.startsWith('物料-') && sub !== '物料') sub = '物料-' + sub;
        return sub;
      }
      let name = fileName.replace(/\.xlsx$/i, '');
      name = name.replace(/[-_]\d{4}[-_]\d{1,2}$/, '');
      name = name.replace(/[-_]\d{4}$/, '');
      name = name.replace(/[-_]\d{1,2}$/, '');
      name = name.replace(/\s+/g, '');
      return '物料-' + name;
    }
    
    // Fallback：取首層資料夾名（去 20xx 年份尾碼），不再回傳 null
    return parts[0].replace(/[-_]?20\d{2}$/, '').trim() || '未分類';
  }
  // ... 其他 QC 標籤處理（QC10006-R01、QC10007-R03 等動態子類別，見原始碼）
}
```

```javascript
const addCategorySheet = (sheetName, qcCode, titleRowText, fixedColumns = null) => {
  const qcCounts = counts[qcCode] || {};
  if (Object.keys(qcCounts).length === 0 && !fixedColumns) return;

  // 欄位來源：fixedColumns（QIP/完成品固定排序）；否則動態展開
  let columns = fixedColumns;
  if (!columns) {
    let dynamicKeys = Object.keys(qcCounts).filter(k => k !== '未分類').sort();
    columns = dynamicKeys.map(k => ({ key: k, label: k }));
    if (qcCounts['未分類']) columns.push({ key: '未分類', label: '未分類' });
  }

  const colData = columns.map(() => Array(13).fill(0));
  columns.forEach((col, colIdx) => {
    const monthly = qcCounts[col.key];
    if (monthly) {
      for (let m = 1; m <= 12; m++) {
        if (monthly[m]) colData[colIdx][m] = (colData[colIdx][m] || 0) + monthly[m];
      }
    }
  });
  // ... 組裝 rows（標題/月份列/1-12月列/小計列，QC10006-R01 無小計）後 book_append_sheet
};
```

## 五、第四層：月份提取邏輯

### 5.1 優先級最高的策略

**實現函數**：[`findDateInSheet()`](../../src/utils/browserETL.js#L149-L196)

**QC10002-R02 專用邏輯**：

case 'QC10002-R02': // 原物料進料品檢

**讀取順序**：
1. 儲存格 `N4` → 解析日期
2. 若失敗 → 儲存格 `O4` → 解析日期

- JavaScript Date 物件
- Excel 日期序列號（40000-50000 範圍）

## 七、潛在風險點分析

### 7.1 風險 R1：子分類匹配過於嚴格

**描述**：
- `原料` 比對仍使用 `===` 精確匹配；`物料` 已改用 `includes('物料')` 模糊匹配（部分修復）
- 其他子分類改走通用 fallback（取首層資料夾名去 20xx 尾碼），`null` 僅來自無關關鍵字排除（空白/舊版/作廢/測試/範例）

**影響**：
- 若使用者建立 `原材料`（多了一個「材」字），不會被跳過，但會以 fallback 名稱（`原材料`）落為獨立子分類，造成欄位分散
- 若路徑包含額外的斜線或空白，可能匹配失敗落入 fallback

**嚴重性**：中高  
**建議**：在 `getRawSubCategory` 中添加容錯機制，允許近似匹配或使用 `includes()` 而非 `===`

---

### 7.2 風險 R2：物料子分類命名不一致

**描述**：
- `getRawSubCategory` 通用分支已將 `物料-塑膠袋40*50`（星號）正規化為 `物料-塑膠袋40X50`
- 但其他變體（如小寫 `物料-塑膠袋40x50`）仍可能產生不同鍵

**影響**：
- 若使用者使用未涵蓋的變體命名，可能無法歸入同一欄位
- 導致數據分散到不同的欄位

**嚴重性**：中  
**建議**：
1. 統一命名規範，強制轉換為大寫 X
2. 在 `getRawSubCategory` 的正規化規則中加入更多備援匹配

---

### 7.3 風險 R3：射出D 的特殊處理衝突

**描述**：
- 在 `getRawSubCategory` 中，路徑包含「射出D」時返回 `射出D` 子分類（歸類為 QC10002-R02）
- 但在 `runETLInBrowser` 的 QC10007-R03 處理區塊中，若路徑包含 `射出D` 但不包含 `射出D(組件)`，會將 actualQC 覆蓋為 `QC10002-R02`

**影響**：
- 可能造成類別混淆，同一個檔案被錯誤分類
- 需要確認業務邏輯是否正確

**嚴重性**：高  
**建議**：審查 QC10007-R03 的覆蓋邏輯，確保不會錯誤覆蓋 QC10002-R02 的映射

---

### 7.4 風險 R4：月份提取依賴多個備援策略

**描述**：
- 若儲存格 N4/O4 無日期，會依序嘗試 9 種備援策略
- 不同策略可能提取出不同月份

**影響**：
- 若檔案名稱包含日期（如 `20250115`），同時路徑也包含月份（如 `原料-1`），可能產生不一致
- 優先順序雖已定義，但若邏輯變更可能導致回溯行為

**嚴重性**：中  
**建議**：
1. 添加日誌記錄，記錄實際使用的策略編號
2. 在 DEV_LOG.md 中追蹤月份提取失敗的案例

---

### 7.5 風險 R5：FOLDER_QC_MAP 匹配順序

**描述**：
- `detectQCFromFolder()` 使用 `Object.keys(FOLDER_QC_MAP)` 遍歷匹配
- JavaScript 物件的鍵順序在 ES2015+ 中是有定義的，但依賴字面順序可能有風險

**影響**：
- 若未來新增的關鍵字與現有關鍵字有包含關係（如「原料」與「原材料」），可能產生歧義

**嚴重性**：低  
**建議**：考慮改為陣列順序，或添加更明確的優先級標記

## 九、建議改進措施

### 9.1 短期改進（優先級高）
